## Introduction

This is an application of BookU is a Blazor web application design with service oriented architecture. The features that are include :
- Search for books using the google Books API.
- View detailed information about selected books.
- Get related news articles using the News API that is related to the book.
- Manager user registration, login, ad session persistence. (This application will need to register or login before using it.)


## API Integration (connected web services)

### Google Books API

- Used search books api and specific book api for getting the data.
- Required access which needed me to register a google account at google console and create API key.

### News API

- In the documentation, News API stated that it can be treated like google api.
- Required access which needed me to register on the website to obtain the API key
